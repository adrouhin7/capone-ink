# Polices Fette Fraktur

## Instructions
Téléchargez le fichier `fette-fraktur.woff2` et placez-le dans ce dossier.

### Sources recommandées :
- [Google Fonts](https://fonts.google.com/)
- [Font Squirrel WOFF2](https://www.fontsquirrel.com/)

Le fichier doit être nommé exactement : `fette-fraktur.woff2`

Une fois ajouté, la police s'appliquera automatiquement sur tous les titres et le logo de Capone'Ink.
